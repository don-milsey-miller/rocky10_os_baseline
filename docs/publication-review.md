# Publication review

The owner requested that the project remain unlicensed for now. No project
license is granted and no open-source release is claimed.

The initial source, catalog descriptions, schemas, tests, and documentation
were independently authored for this project. Primary API documentation was
consulted for tool behavior. No external guide, PDF, control table, numbering
crosswalk, credential file, source specification, or local instruction file is
included in the published tree.

Before publication, inspect the Git file list and diff, scan for credentials
and private-key material, run unit/static checks, and retain VM test evidence
outside Git. Record the tested dependency versions in requirements-tested.txt.

Dependencies are installed separately. Their license metadata is inventoried
in dependency-licenses.json. This is a technical inventory, not a legal opinion
or a grant of rights over dependencies. Redistributing dependencies or issuing
an open-source release requires a separate license decision and review.
